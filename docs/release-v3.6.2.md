# 闲来斗地主 v3.6.2

发牌动画版，versionCode 21，沿用 v3.6.1 的永久证书，可直接覆盖安装并保留牌局、战绩、设置与本地音乐。

## 发牌动画

此前开局只有 3944 ms 的发牌音效，手牌瞬间全部出现，没有任何过渡。现在补上完整飞牌：

- 51 张牌从我、小林、老周三家轮转发出，每 50 ms 一张，单张飞行 340 ms，同一时刻约 6 张在空中，整体约 3.2 秒，跟着发牌音效收尾。
- 牌从我手牌区的最终位置起飞去牌堆，再沿轻微弧线飞回各自的槽位，落点就是它静止时的真实位置，不存在跳动。
- 对手两家没有牌面视图，用一层临时覆盖层承载它们的牌背，飞到座位后收入余牌徽章，数字从 0 同步跳到 17。
- 最后 3 张底牌背面朝上飞向顶部底牌区，发牌期间可见，进入叫分后按原有规则隐藏。
- 发牌期间不显示操作栏；点桌面任意位置可跳过，直接进入正常牌桌。

## 修复

手牌区的牌平时只在"露出的那一条"里画点数，其余部分留白，靠后一张牌盖住。牌一旦飞在空中不再互相遮挡，就会露出大片空白，看上去像一张白牌。现在未被遮挡的牌改为绘制完整牌面，等下一张牌落位把它盖住时再切回窄条绘制——切换正好发生在被遮住的那一帧，看不出来。

## 测试

- 新增设备测试 `nativeDealAnimationCompletes`：发牌运行中断言牌确实停在槽位之外、操作栏为空、底牌区为 3 张背面且可见；结束后断言 17 张手牌全部归位、缩放与透明度复位、临时覆盖层已清空、底牌区重新隐藏。设备测试由 2 项增加到 3 项，`device-check.sh` 相应更新。
- 因为 CI 用 `disable-animations` 关闭动画，`ValueAnimator` 会立即结束，所以测试断言的是结束态；本机在开启动画的情况下另外截取了发牌中的实际画面核对飞行、余牌计数与底牌到达。
- 本机验收：单元测试 22 项通过，`:app:lintDebug` 无错误，1280×720、1920×1080、1.3 倍字体、1280×588 宽屏四种配置各 3 项设备测试全部通过。
