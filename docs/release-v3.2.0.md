# v3.2.0 蓝色经典牌桌版

依据用户提供的 16057.mp4（1280×588）重新制作 Kotlin 原生界面。

- 蓝色织物桌布、两侧圆头像、底部圆头像与本地积分栏。
- 固定步距叠放手牌，牌数减少时居中收拢；白灰渐变牌面、竖排 JOKER、大花色、地主角标。
- 橙色主按钮、蓝紫色辅助按钮、金色时钟；玩家仍不限时。
- 左右对手出牌区与中央自身出牌区；上方免费本地记牌器与地主底牌。
- 删除在线商城、礼包、聊天、段位和小程序入口；仅保留重选、托管、设置及帮助。
- 保持完全离线、无网络权限、三个难度、挖孔全屏及自动存档。

头像来自用户提供的视频参考帧；桌布根据视频参考帧重建。当前 BGM 保持原有离线配乐，视频录音未直接当作 BGM（含人声与出牌声）。不宣称像素级完全一致。

测试签名预发布 APK，实际手机效果仍需验收。
