大牌叠放版，Android 8.0 及以上。

- 手牌改为单排放大叠放，每张牌独立露出大号点数和花色，保留原牌面图案。
- 中央出牌区扩大，顺子、飞机等多张牌采用叠放，减少整体缩小。
- 使用标准平面黑桃、红桃、梅花、方块，避免系统彩色表情替代；10 的字高与其他点数一致。
- 支持点击选牌、横滑连续选牌、反向收回范围和上抬高亮。
- 保留 Kotlin 原生、强制横屏、完全离线、三档人机、音乐音效及自动存档。
- 检查两种分辨率及大字体下的首尾牌真实点击、五张滑选、提示出牌和恢复。附普通、选牌、出牌及 20 张飞机截图。

测试签名预发布版，未经过实体手机验收；覆盖安装若签名冲突需卸载旧版，会清除旧存档。
