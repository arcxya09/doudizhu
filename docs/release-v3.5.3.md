# 闲来斗地主 v3.5.3

包含v3.5.2全局审查修复：叫地主配音、按钮启用状态与纵向居中、旧不出提示清理、选牌后直接不出、48dp辅助按钮命中范围、本地音乐取消清理及异常恢复。

最终截图检查发现宽屏的操作区按比例分配时不足48dp，导致按钮顶部被裁切。此版让操作区保留至少48dp高度，同时保持原中心位置；增加真实全局可见范围检查，覆盖整个按钮和圆角，而不只检查文字。

原生Kotlin、横屏、完全离线。规则模型、牌面、背景、BGM和已接入的声音资源保持本轮版本。

CI规则/配音单元测试、Lint、构建、Android35五种屏幕配置设备验收必须通过后才发布。完整审查见REVIEW-v3.5.2.md。

安装包继续使用CI debug签名，不同构建的签名可能不同；覆盖安装冲突时卸载旧版会删除本地数据，尚无固定正式分发签名与跨签名数据迁移。
