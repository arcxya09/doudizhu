# v3.5.2 全局审查记录

审查范围：Rules/Game、人机策略、MainActivity交互与存档、View/Canvas布局和辅助功能、AudioEngine与本地音乐存储、Manifest、构建与发布。以当前3.5.1代码和用户反馈为基线。

## 已发现并修复

| 问题 | 原因与处理 |
| --- | --- |
| 叫地主读成3分 | 按最高3分提交后复用了叫分音频映射。UI动作独立映射至Order（bid.wav），电脑叫分保留ScoreOrder1/2/3。 |
| 不出始终灰色 | 非主按钮皮肤固定灰色。启用状态使用绿色/金色，禁用状态使用灰色。自由领牌不能不出。 |
| 部分按钮文字偏下 | 灰/绿图的下方阴影计入居中，字体行高与实际汉字边界也不同。按图的实体中心和字形边界计算基线，并统一原生布局的gravity/字体padding。 |
| 已选牌时点不出没有完成动作 | 原交互要求先重选。现在显式不出直接跳过当前手牌选择，合法过牌后清空选中状态。 |
| 新轮领牌仍显示旧不出 | 只清空旧出牌图片，没有清空旧status。新轮领牌时同步清理其他座位提示。 |
| 宽屏小辅助按钮难点 | 视觉高度小于48dp。保留布局，以TouchDelegate扩大命中范围，重叠时取最近中心，原生手牌正常命中优先。 |
| 导入音乐销毁时遗留文件 | 已复制但未提交的文件没有跟随pendingPlayer释放。跟踪pendingSelection，在共享文件队列中核对当前提交指针后删除，避免误删已生效音乐。 |
| 播放中异常可能崩溃 | 准备成功后无播放期错误处理，状态操作未保护。补充错误监听和非法状态恢复；新导入优先，失败后再恢复默认音乐。 |
| 文件信息查询失败阻断有效音乐 | 显示名/大小元数据改为可选，实际流复制仍严格限制32MB。 |

## 检查结论与边界

未发现新的确定性牌型、压制、双过轮转、春天/反春天、计分或农民协作问题。Game/Move/SavedTable结构未改，避免本轮引入Java序列化版本兼容变化。Manifest保持无网络权限、无第三方网络模块。存档和战绩仍一起原子写入，结算标记避免恢复后重复累加。

发布门槛为CI规则/配音测试、Lint、构建，以及Android35五种屏幕配置的两项仪器测试。音频测试注入我们自己的播放器非法状态检查恢复；待导入清理在提交前的异步状态边界注入一个未提交候选，检查销毁后删除且旧已提交文件保留。界面测试检查真实按钮触摸、实际渲染的彩色实体与白色字形，而非仅断言控制变量。规则已有180局全对局及合法组合穷举对照回归。

验收截图和日志随GitHub Actions保存，并在成功后发布Release。模拟器无法代替所有实体手机和人耳判断；本轮设备环境为Android35，未实测所有Android8以上系统。明确保留的分发限制是CI debug签名可能随构建变化，覆盖安装冲突会影响升级体验；尚无固定正式签名和跨签名数据迁移。现有二进制序列化仍不保证以后Game结构变更时的兼容，后续修改该结构需迁移方案。
