# 闲来斗地主 v3.8.0

新增应用内自动更新，versionCode 26。沿用原正式签名，保留牌局、战绩、设置和本地音乐。

- 默认每天在启动时自动检查一次 GitHub 正式版本，发现新版后提示，并在设置入口显示“新”。
- 设置中可手动检查、关闭自动检查、查看更新说明与安装包大小。
- 确认后下载，展示进度，支持取消和完整安装包复用；断网或下载失败不影响离线对局。
- 安装前检查文件完整性、包名、递增版本、系统兼容性及固定正式签名，再交由 Android 授权和确认安装。
- 更新检查与牌桌调度独立，切后台、取消或退出不会因迟到回调误弹安装界面。

此版本开始申请联网与安装更新权限；对局仍可完全离线，不上传牌局、战绩或音乐，不需要存储权限。

**已安装 v3.7.0 或更早版本的玩家，需要先手动覆盖安装本版一次，之后才能使用应用内更新。** 不要卸载旧应用，以免清除本地数据。不同签名的早期测试版不支持直接覆盖更新。

更新功能说明及验证边界见 [应用内更新](https://github.com/arcxya09/doudizhu/blob/v3.8.0/docs/UPDATES.md)。
