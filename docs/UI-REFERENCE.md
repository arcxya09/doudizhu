# 视频 UI 对照

参考：用户提供的 16057.mp4，1280×588。v3.2.1 使用 Kotlin View / Canvas 绘制动态界面，贴图仅用于桌布和圆头像。

| 区域 | 实现 |
| --- | --- |
| 桌布 | 蓝色织物、底部弧形缝边与叶片 |
| 对手 | 左右圆头像，身份、姓名、余牌数字 |
| 顶部 | 免费本地记牌器、地主底牌、重选、托管、设置 |
| 操作区 | 橙色主按钮、蓝紫色辅助按钮、金色时钟 |
| 手牌 | 下方居中，固定叠放步距；牌数减少后收拢；竖排 JOKER 与地主角标 |
| 出牌 | 左右两区加中央一区，长牌型分行，避免交叠 |
| 底栏 | 本地身份、积分、已选牌提示、倍数、帮助 |

视频中的回归礼包、商业记牌器有效期、促销侧栏、聊天、段位、小程序胶囊和系统时间均不接入应用。玩家没有强制倒计时，界面显示 ∞。保留本地三档难度、存档、音乐音效和速度设置。

v3.2.0 的五种显示配置已通过自动验收。v3.2.1 补充宽屏叠牌遮挡与回合提示修复，使用相同的五种配置验收：1280×720、1920×1080、字体 1.3 倍、1280×588、系统模拟挖孔。Release 附真实运行截图。
