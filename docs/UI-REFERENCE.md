# 视频 UI 对照

参考：用户提供的 16057.mp4，1280×588。v3.3.0 使用 Kotlin View / Canvas 绘制动态界面，贴图用于桌布、圆头像和参考扑克牌角标。

| 区域 | 实现 |
| --- | --- |
| 桌布 | 蓝色织物、底部弧形缝边与叶片 |
| 对手 | 左右圆头像，身份、姓名、余牌数字 |
| 顶部 | 免费本地记牌器、地主底牌、重选、托管、设置 |
| 操作区 | 橙色主按钮、蓝紫色辅助按钮、金色时钟 |
| 手牌 | 下方居中，按17/20张参考跨度计算叠放步距；牌数减少后收拢；竖排 JOKER 与地主角标 |
| 出牌 | 左侧贴左、右侧贴右、自己居中；长牌型叠放分行，避免点数被遮住 |
| 底栏 | 本地身份、积分、已选牌提示、倍数、帮助 |

视频中的回归礼包、商业记牌器有效期、促销侧栏、聊天、段位、小程序胶囊和系统时间均不接入应用。玩家没有强制倒计时，界面显示 ∞。保留本地三档难度、存档、音乐音效和速度设置。

v3.2.0 的五种显示配置已通过自动验收。v3.2.1 补充宽屏叠牌遮挡与回合提示修复，使用相同的五种配置验收：1280×720、1920×1080、字体 1.3 倍、1280×588、系统模拟挖孔。Release 附真实运行截图。

3.3.0 进一步按参考校正按钮实体为宽约116 px、高56 px（1280×588画面），保持48 dp点击高度；17张牌可见范围约 x163–1117、y373–537，牌身宽高比0.76。开叫阶段隐藏记牌器和底牌，战绩移到设置页。桌布降低饱和度，底栏去掉空闲提示。
