首个 Android 离线测试版。下载下方 `doudizhu-1.0.0.apk` 安装，支持 Android 8.0 及以上，系统 WebView 需支持现代 JavaScript（建议 100 及以上）。

- 简单、普通、困难三档本地人机，不读取对手暗牌。
- 叫地主、全部常见牌型、提示、自动续局和本机战绩。
- 无网络权限，无广告、账号、内购或远程资源。
- 已通过规则与 180 场人机对局自动测试、桌面 Chromium 手机尺寸界面冒烟测试、APK 编译与 Android lint。

本安装包采用开发测试签名，尚未完成 Android 真机验收。请在飞行模式下试用。不同构建的 debug 签名可能不同，长期维护版需配置固定签名。
