横屏大牌与声音更新。下载 `doudizhu-1.1.0.apk` 安装。支持 Android 8.0 及以上，建议系统 WebView 100 及以上。

- 固定横屏（可左右翻转），两排大牌，实体扑克牌式牌角、花色点阵和双向人物牌。
- 放大文字、身份标记和按钮，提高文字对比度；20 张手牌均可直接点选。
- 增加本地原创合成背景音乐，以及选牌、出牌、不出、炸弹、轮到玩家和胜负音效。首次触摸开始声音；切后台自动暂停。音乐和音效可单独关闭，可调音量。
- 电脑默认舒缓速度，可选更慢；玩家不限时。声音和速度设置自动保存。
- 禁止空选、无效牌型或压不过上家时出牌；已选牌误点不出时提醒。
- 仍完全离线，无网络权限、广告和内购。

验证：规则与 180 场自动对局、三种横屏尺寸界面和 48px 手牌触控区域、选牌与提示、声音设置持久化、续局、APK 构建和 Android lint。未进行 Android 真机验收。

此版使用开发测试签名。若旧版安装提示签名冲突，需要卸载旧版后安装，本机牌局和战绩会随卸载清除。
