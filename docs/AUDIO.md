# 离线参考录音音频

v3.3.0 删除了此前由正弦波生成的背景旋律和提示音。音频现在来自用户在本次改版中上传的 `16057.mp4` 参考录屏，随 APK 一起打包，播放时不读取网络、不下载文件。

## 背景音乐的实际范围

`audio/table_loop.wav` 使用录屏约 2.12–18.82 秒的八小节乐段，循环长度为 **16.695646 秒**，头尾采用 120 毫秒交叉淡化。

处理时先选取无动作等待区间建立伴奏频谱参考，再利用录屏中相隔 30.628571 秒的重复伴奏作相位一致性校验。无动作片段保留原录音，叫地主、发底牌、加倍等有前景声音的片段采用频谱掩膜抑制。与 30.63 秒的候选相比，当前 16.70 秒版本避开后半段密集的飞机、报牌和两次“不出”，同时减少短循环重复感。

这是从混合录屏恢复出的**乐段循环**，并非完整原版 BGM 或无损独立母带。掩膜可能损失部分乐器细节，也不能保证所有低电平声音均被完全去除。独立音频源仍能进一步改善质量。处理和设备测试不能代替人工听音验收。

`provenance.json` 记录各事件窗口处理前后的均方根能量变化及接缝指标。能量衰减包含部分音乐成分，不应解读为严格的语音分离信噪比或主观音质评分。

## 播放行为

- `MediaPlayer` 播放本地背景音乐并循环，`SoundPool` 播放本地操作声音。
- 报牌和特效播放时暂时降低背景音乐音量；连续报牌不会重叠多个语音。
- 关闭音效立即停止正在播放的短音，关闭音乐立即暂停 BGM。
- 切到后台、音频焦点丢失或页面销毁时停止声音；恢复前台后依设置恢复背景音乐。
- 保留背景音乐、音效两个开关及总音量设置。
- 全部资产为 22050 Hz、单声道、16 bit PCM WAV。最长短音为 2.86 秒，避免 SoundPool 长音解码限制。

## 复现

原录屏不纳入仓库。安装 ffmpeg、NumPy、SciPy 后运行：

```sh
python scripts/extract-reference-audio.py /path/to/16057.mp4
```

脚本会在 `app/src/main/assets/audio/` 生成音频及 `provenance.json`，记录源片段、时长、峰值和均方根幅度。设备验收检查打包资源可解码、循环播放、声音设置和前后台状态，不以这些检查宣称听感与原游戏完全一致。
