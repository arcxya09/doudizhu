# 闲来斗地主 v3.6.4

提示按钮状态修复版，versionCode 23，沿用 v3.6.1 起的永久证书，可直接覆盖安装并保留牌局、战绩、设置与本地音乐。

## 问题

"提示"按钮此前始终可点。手里没有任何能压过上家的牌时，点下去只会把一句说明写到底部文字里（"没有能压过的牌，请点不出"），按钮本身看起来仍然是可用的，容易让人反复点。

## 修复

- 当前无牌可出时，"提示"按钮**变灰不可点，文字改为"无可出"**。
- 判断条件是出牌生成器对当前牌面的结果为空：`Rules.moves(手牌, 上一手).isEmpty()`。自由出牌（上一手为空）时必然有牌可出，因此跳过生成器，只在需要压牌时才计算。
- 地主队友协作导致的"建议不出"不属于无牌可出——那种情况手上仍有合法出法，按钮保持可点，提示仍显示"建议让农民队友继续出牌"。
- 按钮宽度不变（"无可出"与"提示"同属短标签档位），不会因为换文字而跳动。

## 测试

- 设备测试新增两条断言：把上一手设成王炸（无任何牌型可压）后按钮文字为"无可出"且 `isEnabled` 为 false；清空上一手后按钮恢复为"提示"且可点。
- 该状态会截图归档（`native-no-hint.png`），并由 `device-check.sh` 一并拉取。截图复用既有的 `captureGame` 校验，它会顺带断言按钮文字完整可见——"无可出"在 1.3 倍字体与 1280×588 宽屏下都不被裁切。
- 本机验收：单元测试 22 项通过，`:app:lintDebug` 无错误，1280×720、1920×1080、1.3 倍字体、1280×588 宽屏四种配置各 3 项设备测试全部通过。
