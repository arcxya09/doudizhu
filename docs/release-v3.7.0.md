# 闲来斗地主 v3.7.0

牌桌交互、电脑策略与存档修复版，versionCode 25。延续 v3.6.1 起的正式签名；从同签名正式版覆盖安装可保留牌局、战绩、设置及本地音乐。

## 牌桌与操作

- 顶部显示轮到谁、自由出牌或需要接牌，底栏提供操作说明。
- 选中手牌增加淡金底色和描边，改善记牌器、当前座位和禁用按钮的可读性。
- 修复点击抬起牌时误选邻牌，多指或系统打断滑选时恢复原选择。
- 帮助按钮打开独立玩法说明；托管切换清除过时选择，并改善手牌无障碍描述。
- 修复发牌期间电脑提前叫分、领底牌而打断动画的问题。

## 电脑策略

- 精确计算自身手牌最少出手数，覆盖三带二、飞机翅膀、四带及重叠顺子；按点数缓存并消除花色重复搜索。
- 结合散单负担与高对子控牌评估候选，改进农民喂牌和对即将走完的地主的拦截。
- 王炸后能一手收尾时保住出牌权，面对王炸立即不出。
- 仍只使用自身手牌与公开信息，不读取对手暗牌。

完成 3,000 局固定种子新旧对照。农民协作样本有所改善，地主结果随样本波动，不把单组胜率推广为所有局面的提升。完整结果及复现方式见 [AI 审查记录](https://github.com/arcxya09/doudizhu/blob/v3.7.0/docs/AI-REVIEW.md)。

## 存档与声音

- 牌局和战绩一起原子保存，成功后再更新独立战绩镜像，避免写入失败导致重复计分。
- 强化座位、牌张、轮转和结算一致性校验；旧 v2/v3 存档继续可读。
- 支持仅剩备份文件时恢复；损坏当前存档不再复活过时旧局，独立战绩保留。
- 损坏的自选音乐回退默认并清理失效选择；异常旧音量限制在有效范围。

## 验证

本机完成规则、存档兼容、原生触控、声音和五种模拟器屏幕配置验收。正式发布另外经过 GitHub Actions 的 Android 35 设备测试、固定证书与非调试检查，以及从上一正式版实际覆盖安装的数据保留验证。升级校验允许存档兼容迁移，但严格比较牌局及战绩语义，设置与音乐文件保持一致。

详细问题与验证边界见 [全软件审查记录](https://github.com/arcxya09/doudizhu/blob/v3.7.0/docs/REVIEW-2026-10-09.md)。
