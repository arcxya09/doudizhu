# 闲来斗地主 v3.5.2

本次完成规则、人机、交互、存档和音频的全局审查。

- 点“叫地主”播放原资源的“叫地主”语音；电脑明确叫分仍读对应分数。
- 可用的“不出”等普通按钮显示绿色，主操作显示金色，不可用状态显示灰色；自由出牌时不能不出。
- 按按钮实体和可见字形居中，修复绿色/灰色贴图底部阴影导致文字偏下；设置页也使用一致的按钮文字布局。
- 选牌后可以直接点“不出”，新一轮领牌清除上一轮的不出提示。
- 顶部工具与帮助等小按钮扩大到至少48dp命中范围，保持原视觉位置并避开挖孔区域。
- 取消音乐导入时删除未提交文件，保留已提交选择；播放中出现非法状态或解码错误时安全恢复默认音乐。文件信息查询失败仍允许读取有效的本地音频。

原生 Kotlin、强制横屏、完整离线，继续使用已接入的原始牌面、背景和音频资源。

CI 必须完成规则/配音单元测试、Lint、原生 APK 构建和五种 Android 35 屏幕配置设备验收后才发布，覆盖字体放大、宽屏和挖孔。新增设备回归检查按钮真实点击配音、启用/禁用贴图、文字可见字形居中、选牌后不出、过期提示清除、扩展区域点击、取消导入清理和播放错误恢复。完整记录见 REVIEW-v3.5.2.md。

此安装包继续使用 CI debug 签名；不同构建的签名可能不同，覆盖安装冲突时卸载会删除本地数据。当前未提供正式分发签名或跨签名数据迁移。
