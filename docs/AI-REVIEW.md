# 本地 AI 审查与复现

本轮修复了手牌评估遗漏三带二、飞机翅膀、四带附件和重叠顺子的问题。新的 `HandEvaluator` 只搜索自身手牌，按点数编码共享缓存，计算最少合法出手数；策略另外考虑低散单、高对子、队友让牌及残局拦截。农民会在下家地主可能用最后一张/一对压过队友时拦截，但不会盖住已不可被超越的队友。王炸加一手合法余牌时先用王炸保住出牌权。

出牌生成器按翅膀点数及数量枚举，避免同一种点数组合因花色不同反复计算。面对王炸时直接返回不出。序列化模型及 UID 未改动。

## 可复现基准

先完成一次 Gradle Debug 构建，确保 Kotlin 2.0.21 编译器及依赖已进入 Gradle 缓存。需要 Python 3、Git 和 JDK 17 或更高版本；`JAVA_HOME` 或 `--java` 指定 Java，`GRADLE_USER_HOME` 可指定缓存。工具不会修改应用源码或存档。

```sh
python3 scripts/benchmark-ai.py --baseline-ref b0dbe28760053225c0d4cbb17e77e551df056066 --seed-start 1 --games 300 --samples 300
python3 scripts/benchmark-ai.py --baseline-ref b0dbe28760053225c0d4cbb17e77e551df056066 --seed-start 401 --games 300 --samples 300
```

Windows 可使用 `python` 并补充 `--java "C:/Program Files/Android/Android Studio/jbr/bin/java.exe"`。仅验证工具时使用 `--games 3 --samples 3`。

脚本从指定 Git revision 读取旧 AI，在 `app/build/ai-benchmark/` 独立编译，不把旧策略加入 Android 应用。生成的 `results-<起始种子>-<局数>.txt` 包含旧版本提交号、当前两个算法文件的 SHA256、各组地主胜局数和桌面 JVM 时延。固定座位 0 为地主并叫 3 分，三种同级交叉对照共用相同种子范围；不同策略会消耗不同数量的随机值，因此这些样本不是逐动作一致的配对实验。

## 本轮观察

2026-10-09 对最终代码串行重跑两个种子范围，每个范围完成五组各 300 局对照，共 **3,000 局**。原始输出保存在 [种子 1–300](benchmarks/ai-final-1-300.txt) 和 [种子 401–700](benchmarks/ai-final-401-300.txt)，并记录旧版提交号及当前源码 SHA256。两次均使用 `Rules.kt` 的 SHA256 `098a430d6f8e6742f59dd06fef189e02746364f0cb00311379386e04a1ee5692`，已包含最后的队友喂牌例外。

最终代码的同级交叉对照如下，数值均为固定地主的胜局数：

| 种子 | 新地主 / 旧农民 | 旧地主 / 新农民 | 旧地主 / 旧农民 |
| --- | ---: | ---: | ---: |
| 1–300 | 138/300 | 129/300 | 143/300 |
| 401–700（留出样本） | 140/300 | 125/300 | 132/300 |

对应的新困难地主对新简单农民分别为 **250/300**、**247/300**；新简单地主对新困难农民分别为 **6/300**、**10/300**。这些固定座位、固定种子样本不能用于宣称总体胜率提升。观察支持保留确定的拆牌、协作及残局修复；地主结果随样本浮动。

每次对局测试后，时延采样另覆盖三种密集 20 张手牌及 300 手随机地主牌，结果为桌面热 JVM 数据：

| 随机手牌种子 | 样本数 | 平均 | P95 | 最大 |
| --- | ---: | ---: | ---: | ---: |
| 1–300 | 303 | 1.95 ms | 4.77 ms | 24.76 ms |
| 401–700 | 303 | 1.19 ms | 3.06 ms | 6.39 ms |

时延受 JVM 预热和机器负载影响，不能代替手机上的时延验收。本机使用 `C:\Users\Ryan\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe` 与 Android Studio 自带 JDK 执行上述脚本；普通 Python 3 环境同样可运行。

回归测试另用独立子集动态规划核对最少出手数，穷举密集飞机/炸弹手牌核对出牌生成器，并覆盖队友拦截、不可被超越的队友牌、王炸两手收尾、喂牌及三个难度的完整对局。
