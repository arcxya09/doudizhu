# 闲来斗地主 v3.6.3

音量控制修复版，versionCode 22，沿用 v3.6.1 起的永久证书，可直接覆盖安装并保留牌局、战绩、设置与本地音乐。

## 问题

设置里只有一个"声音大小"滑块，音乐和音效共用它，但两者的上限并不相同：

```kotlin
val level = volume / 100f * .4f      // 音乐：再乘 0.4
val level = volume / 100f * .9f      // 音效：乘 0.9
```

于是滑块拉到 100% 时音乐也只能到 −26.7 dBFS，音效却能到 −16.8 dBFS，**用户没有任何办法把 BGM 调得比音效响**。滑块在 45 时的实际输出是音乐 −33.6 dBFS、普通音效 −23.8 dBFS、发牌 −29.7 dBFS，发牌比音乐还响。

`deal.wav` 实测 RMS 为 −21.8 dBFS，其实是所有素材里最轻的（多数报牌音效为 −15.9 dBFS）。它听起来吵，是因为它是 3.94 秒的连续声音，而报牌多为 0.5 秒短音；长达 4 秒的持续声掩蔽感强，期间音乐还被压低到 0.38 倍（−42 dBFS），于是每次开局都像"音乐没了、发牌很吵"。

## 修复

- **拆成两个独立滑块**，音乐与音效各自控制、各自持久化，互不影响。设置页显示实时百分比（音乐音量 / 音效音量），拖完音效滑块会播一声 `play` 试听。
- **音乐上限由 0.4 提到 1.0**，滑块拉到 100% 可到 −18.7 dBFS，第一次真正能把 BGM 调响。
- **发牌音效单独乘 0.75**，它是长音，不应按短报牌的音量播。
- 默认值音乐 60、音效 55。默认输出：音乐 −23.1 dBFS、普通音效 −22.0 dBFS、发牌 −30.4 dBFS——发牌由原来比音乐响 3.9 dB 变为比音乐轻 7.3 dB，音乐整体提高 10.5 dB。
- 老版本存的单值 `volume` 会自动迁移到两个新值，不重置已有选择；旧键保留，降级安装仍可读。

## 测试

- 设备测试补充两条通道互不影响的断言：音乐音量为 0 时音效照常播放、音效音量为 0 时音乐照常播放且立即停止短音，两个值分别独立保存。
- 本机验收：单元测试 22 项通过，`:app:lintDebug` 无错误，1280×720、1920×1080、1.3 倍字体、1280×588 宽屏四种配置各 3 项设备测试全部通过；设置对话框在四种配置下都能滚动到全部分区。
