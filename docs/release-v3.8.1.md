# 闲来斗地主 v3.8.1

修复发牌动画与操作按钮，versionCode 27。沿用原正式签名，可直接覆盖安装并保留牌局、战绩、设置和本地音乐。

- 电脑收牌位置改为实际余牌徽章中心。牌背接近时缩小并淡出，抵达后计数增加，不再停留一叠大牌背或偏向屏幕边缘。
- 用真正的牌面中心计算飞行轨迹，让手牌、电脑牌和底牌从同一位置发出；正确处理刘海安全区及各容器偏移。
- 布局完成后才开始发牌；跳过、重新发牌、切后台或窗口尺寸改变时清理旧动画。
- 修复自己的飞牌被手牌容器上边缘裁掉；飞行中的牌显示完整大花色，开局不再短暂闪出全部手牌，发牌结束后再显示电脑回合钟。
- 黄色高亮、普通绿色和禁用灰色按钮统一实体边界与文字中心，保留完整光晕、阴影及 48 dp 点击高度；按下时不改变位置。
- 叫分操作按实际可用宽度排布，避免小窗口中按钮遮住对手余牌数。
- 修复窄屏配合大字号时对手姓名、牌桌提示、工具栏和帮助文字被裁掉，保留合适的文字高度与间距。

已安装 v3.8.0 的玩家可从设置里的应用内更新下载本版；每天的自动检查也会发现本版。更早版本可从本 Release 手动下载覆盖安装，无须卸载。

验证包含实际牌面中心、收牌计数与消隐、重新开局及后台恢复、按钮实体像素与文字基线、小窗口动作行，以及真实屏幕截图中的飞牌可见性。裁剪回归测试已验证会在未修复版本失败。发布前本地 50 项单元测试和标准屏 31 项设备测试通过，Lint 无错误（51 项提示）；发布流程另运行多屏幕验收和上一正式版的实际覆盖升级检查。未进行实体手机实测。
