Kotlin 原生重写版。界面使用 Android View / ViewGroup / Button / TextView，卡牌使用本地 WebP 牌面贴图；不包含 WebView、HTML、CSS 或 JavaScript。

- 原生横屏全屏牌桌，按可用空间测量布局，手牌长宽比固定，触控区域互不重叠。
- 完整实体牌面贴图、放大牌角、选牌标记、清楚的地主身份与剩余张数。
- Kotlin 规则与三个难度的本地人机，原生存档、设置、对话框。
- MediaPlayer 循环背景音乐与 SoundPool 出牌音效，后台暂停，音频焦点管理。
- 仍不申请网络权限，无广告、无内购；Android 8.0 及以上。

此版本通过 Kotlin 规则测试、180 局固定种子对局、APK 编译与 lint，以及 Android 模拟器两种分辨率下的布局、选牌、出牌和重启续局测试。截图见附件。尚未进行实体手机验收。

安装包使用开发测试签名。如与旧版签名冲突，需卸载旧版安装；旧 WebView 版牌局和战绩不迁移至原生版。
