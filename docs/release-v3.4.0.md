根据用户提供的站长素材页面更新五种短音，并增加本地背景音乐导入。

- 换用独立的叫地主、飞机和王炸短音；新增洗牌与“要不起”。只在没有合法跟牌时播放“要不起”，主动让牌继续使用“不出”。
- 音频去除首尾长静音、统一音量，全部打包到 APK，播放无需联网。
- 设置中可选择手机里的音乐文件，导入后自动保存，重启继续使用；可恢复默认乐段。损坏或超限文件不会覆盖已有音乐。
- 音乐关闭时导入保持静音；后台暂停、前台恢复、音频焦点及音效开关继续生效。
- Kotlin 原生界面、横屏全面屏、三档人机和本地存档保持。

默认 BGM 仍为用户录屏提取的约16.7秒乐段。素材站的33秒音乐未确认与录屏相同，且页面未明确授予整段音乐的公开再分发许可，因此没有将该音乐捆绑到公开安装包。可以在手机上下载自己选用的音乐，再从应用设置导入。

短音来源与处理记录见 docs/AUDIO.md 及 assets/audio/site_provenance.json。素材站标注“仅供学习与参考，请勿用于商业用途”，这些资源没有被重新标为自由素材。

本版为 debug 签名预览包；覆盖安装若发生签名冲突，卸载旧版会清除本地存档、战绩和已导入的音乐。
